5. GITHUB & VERCEL DEPLOYMENT (ZERO CONFIGURATION):
---------------------------------------------------
This project is pre-configured to build cleanly on Vercel without 404 errors:

To push to GitHub:
Method A (Easiest - GitHub Web UI):
1. Go to https://github.com/new and create a new repository (e.g. "priorix-support").
2. Extract "PRIORIX_Website_Submission.zip" or open your "GAT" project folder.
3. Click "upload an existing file" on GitHub, drag all files in, and commit.

Method B (Using Git):
1. git init
2. git add .
3. git commit -m "feat: deploy PRIORIX support system"
4. git branch -M main
5. git remote add origin https://github.com/<your-username>/<your-repo-name>.git
6. git push -u origin main

To deploy on Vercel:
1. Go to https://vercel.com and log in.
2. Click "Add New..." -> "Project".
3. Import your GitHub repository.
4. Keep all default settings (Root Directory as ./, Framework Preset as Vite).
5. Click "Deploy".
6. In ~30 seconds your website is live worldwide with full ticket management,
   15 real-life enterprise tickets, and AI triage!
